
Relational database stores data in table format
Tables are connected by relationships.


It tells what post belongs to 1 user. 

one user can have many post - one to many relationship


non-relational db -> does not organise data using connected tables. They use tables and key value pairs. 

### When is relational db a good point?
1. Data has clear structure.
2. Data has relationships
3. Data has transactions,
4. Data has strong validation at db level
5. uses join.
example of app to use relational db:
- banking app, 
- ecommerce app,
- crm app.

## Non relational db
Used when data changes very often, documents are independent, you don't need more joins etc..
